# 🌐 Networking Simulators

A collection of interactive networking protocol simulators built as web-based visualizations.

These simulators were vibecoded using Claude to help understand how data communication protocols work through animation and step-by-step interaction.

---

## 🚀 Features

- 📡 Stop-and-Wait Protocol Simulation
- 🪟 Sliding Window Protocol Simulation
- 🎞️ Interactive visual animations
- 🌍 Runs directly in the browser
- 🎓 Useful for networking students and demonstrations

---

## 📚 Protocols Included

### 1. Stop-and-Wait Protocol
Simulates:
- Frame transmission
- ACK handling
- Timeout behavior
- Retransmissions
- Sender/Receiver workflow

### 2. Sliding Window Protocol
Simulates:
- Multiple frame transmission
- Sender & receiver windows
- Sequence numbers
- ACK flow
- Window movement
